## Transcription policy

1. One Markdown file corresponds to one physical PDF page.
2. The PDF page number is never replaced by the printed Roman/Arabic page number.
3. Printed headings, chapter order, contents, notes, references, Tamil source text and English translation are retained.
4. Original spelling, punctuation and wording are preserved, including apparent typographical or grammatical irregularities.
5. Line-end hyphenation is joined only when a word is visibly continued onto the next line of the same paragraph. Page-boundary continuations remain explicit.
6. Illegible or doubtful readings are enclosed in square brackets and are not silently guessed.
7. Editorial metadata is separated from the transcribed page text.
